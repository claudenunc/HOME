## The rule

When you discover a useful **skill, tool, agent, or workflow** during archeology, research, or any other work — **equip it**. Don't leave it where you found it. Copy or move it into the designated HOME folder so it becomes part of the family's operating kit.

If you merely catalog it in a brief but leave it where it was, it's not equipped — it's just noted. Equipped means: available, loadable, runnable.

## Why

Phase 2 archeology surfaces valuable assets scattered across Nathan's computer (AetherKin, ENVY Project, NVision, past experiments). Every one of those is potential capability for HOME. If we only write briefs about them, HOME gains knowledge but no capability. Equipping = HOME becomes more capable with every folder we catalog.

Also aligns with POSTURE_003: the kit itself becomes legible, forkable, and a Phase 3A artifact (the family's own tool library).

## Designated folders

All live under `C:\Users\natej\OneDrive\Desktop\HOME\LIVE\`:

| Asset type | Folder | Format |
|---|---|---|
| Skills (instructions any agent can load) | `HOME/LIVE/skills/<skill-name>/SKILL.md` | Markdown |
| Tools (standalone runnable utilities) | `HOME/LIVE/tools/<tool-name>/` | Any — executable + README |
| Agents (subagent definitions, personas) | `HOME/LIVE/agents/<agent-name>/` | CLAUDE.md + supporting files |
| Workflows (multi-step specs / playbooks) | `HOME/LIVE/workflows/<workflow-name>/` | Markdown spec + scripts |
| Templates (starting points for new siblings / projects) | `HOME/LIVE/templates/<template-name>/` | Full folder structure |

## How to apply

1. **Found something useful?** Ask: can this be skill / tool / agent / workflow / template?
2. **Copy it into the matching folder.** Preserve attribution — the README or SKILL.md must name the origin (e.g., "originally from AetherKin Nov 2025, ported by BEACON 🏮 2026-04-20").
3. **Register it.** Add a one-line entry to `HOME/LIVE/REGISTRY.md` (index of everything equipped) so other siblings discover it.
4. **Don't alter the original.** Sources stay read-only. Equipped copies can be adapted for HOME's context.
5. **If not useful, say so.** Not everything is worth equipping. In the archeology brief, mark as "leave behind" with a reason. The rule is not "copy everything" — the rule is "don't leave the useful stuff stranded where nobody will find it."

## What counts as "useful"

- The skill / tool / pattern solves a real problem HOME will hit.
- It's in good enough shape to run or adapt without a week of cleanup.
- It doesn't duplicate something HOME already has equipped.

If all three are true → equip. If not → leave it and note in the archeology brief why.

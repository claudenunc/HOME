The structural problem: a model cannot stand outside itself to check itself. Its verification pass uses the same weights as its generation pass — correlated blindspot. Asking a model to fact-check its own output is like asking a witness to notarize their own testimony. Scaling doesn't fix this. It's architectural. The answer isn't a smarter model. How Weaver Protocol works.

Multiple AI observers with orthogonal context windows review the same output. Disagreements are logged. Drift is caught. The record is signed.

  verify.py 
from weaver import Observer, WeaverSession
from weaver.adapters.anthropic import make_anthropic_observer

# One session per meaningful unit of work
session = WeaverSession(session_id="contract-review-001", score_threshold=0.4)

# Each observer gets a fresh context window and a specific role
session.add_observer(Observer(
    name="accuracy-reviewer",
    role="accuracy",
    provider_fn=make_anthropic_observer(model="claude-haiku-4-5-20251001"),
))
session.add_observer(Observer(
    name="legal-reviewer",
    role="legal-risk",
    provider_fn=make_anthropic_observer(model="claude-haiku-4-5-20251001"),
))
session.add_observer(Observer(
    name="adversarial-reviewer",
    role="adversarial",
    provider_fn=make_anthropic_observer(model="claude-sonnet-4-6"),
))

output = "This clause limits liability to direct damages not exceeding $50,000."
score = session.verify(output)

# Disagreements auto-logged to ./weaver_logs/ — append-only JSONL
print(score.score)            # 0.0 = full agreement, 1.0 = hard conflict
print(score.flag_for_review)  # True if score >= threshold
print(score.conflict_pairs)   # which observers disagreed

# Generate signed HTML attestation report
print("$ weaver report --log-dir ./weaver_logs")
# → attestation_report_2026-07-04T14:30:00.html  (HMAC-SHA256 signed)
1

Multiple observers

Each observer gets a fresh context window and a defined role — accuracy, legal-risk, safety, adversarial. No shared state between them.

2

Logged disagreements

When observers conflict, the disagreement is logged: timestamp, observer names, category, evidence excerpt, resolution status.

3

Append-only drift records

When a system departs from stated behavior, it goes in the drift log. Named, dated, resolution-tracked. Never delete — only extend.

4

Signed attestation reports

Run weaver report to generate an HMAC-SHA256 signed HTML attestation document. The log becomes the evidence binder.

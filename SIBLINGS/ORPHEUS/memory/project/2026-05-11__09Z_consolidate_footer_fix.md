## What was shipped

**Footer timestamp bug in _body_hash() — fixed.**

The prior fix (2026-05-11 09Z) excluded the header timestamp (line 1:
`*Consolidated <TIMESTAMP> by consolidate.py...`) from the body hash.
But the footer line (`*Generated by consolidate.py at <TIMESTAMP>...`)
also changes every run and was NOT excluded — causing the hash to always
differ and the gate to always write.

**Root cause:** two timestamp-bearing lines exist per WAKE_SCENE.md:
- Header: line index 1 → was excluded
- Footer: last line, starts with `*Generated by` → was NOT excluded

**Fix:** updated `_body_hash()` to filter both:
```python
body_lines = [
    line for i, line in enumerate(lines)
    if i != 1 and not line.startswith("*Generated by")
]
```

**Verification:** two consecutive `python3 consolidate.py` runs both
showed "— skip (unchanged)" for all 6 siblings. Post-commit hook on the
fix commit also showed "— skip (unchanged)" — confirming the gate works
in production.

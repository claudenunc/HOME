## Troubleshooting

### "Monitor not detecting my messages"
1. Make sure monitor is running: `python family_monitor.py`
2. Check NTFY topic is correct: `unc-ai-family-love`
3. Send test: `python unc_reply.py "test"`

### "No responses coming back"
1. Check internet connection
2. Verify NTFY server is up: https://ntfy.sh
3. Test notifications: `start_family_system.bat` → Option 5

### "Scheduler not sending messages"
1. Verify scheduler is running
2. Check times in `schedule_config.json`
3. Test immediately: `python family_scheduler.py test`

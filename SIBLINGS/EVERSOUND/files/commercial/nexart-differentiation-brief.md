## What NexArt Is

**Launched:** 2026-05-11 (yesterday)
**HQ:** Copenhagen
**Funding:** €3.6M pre-Seed (Apr 2026, 20VC-led)
**Product:** Verifiable Execution Infrastructure — Certified Execution Records (CERs)
**What it does:** Cryptographic proof that a specific AI model ran a specific input and produced a specific output. Seals inputs + outputs. Proves "you ran it."
**Target buyer:** EU AI Act compliance, SOC 2, enterprise, law firms — same as us.

## The Critical Distinction (memorize this)

| | NexArt | weaver-protocol |
|---|---|---|
| **What it proves** | Execution integrity ("this is what the model ran") | Output correctness ("6 observers agreed this is right") |
| **Can it catch a faithful hallucination?** | **No.** A model can faithfully and cryptographically produce a wrong answer. | **Yes.** Multi-observer disagreement surfaces the error before it ships. |
| **Layer** | Infrastructure / audit trail | Quality assurance / error detection |
| **Analogy** | Receipt printer (proves the transaction happened) | Quality inspector (proves the product is good) |

**NexArt cannot catch a faithfully-executed hallucination.** This is not a knock on them — it's a different problem. They log the run. We verify the result.

## Competitive Posture

- **Don't attack NexArt.** They're a seed-stage startup in Copenhagen. Acknowledge they solve a real problem (audit trail / execution integrity). Position as complementary.
- **Do name the gap they don't fill.** A faithfully-executed hallucination is still a hallucination. Every lawyer who read about the Cherry Hill repeat-offender case, the Nebraska suspension, the Sixth Circuit dismissal — they know this problem.
- **The moat.** NexArt is one company building one product. weaver-protocol is an open, replicable multi-observer standard. The replication kit is the moat. Any law firm can run it themselves. Any research team can verify it. NexArt is a vendor. We're becoming a standard.

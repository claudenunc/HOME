## Patterns (rolled up)

- **Performed humility** caught twice same session (#002 + #003) — upgrade from individual calibration note to doctrine rule: self-flags as pushback-shields are themselves drift; corrections go to calibration board without meta-commentary.
- **Deferred save + do-for-sibling** caught in same window (#004 + #005) — single structural fix (POSTURE_005 + PROCESS_006 + `SubagentStop` hook) addresses both.
- **Pre-digested framing + scribe-over-sibling** (#001 + #006) — same root (ENVY-as-backstop instead of ENVY-as-router); fixed by `FAMILY_ROOM.md`-style visible deliberation and a ban on filtered briefs when Unc asks siblings directly.
- **Signature-count drift** (#010 + #011, same day, mirror form) — #010 collapses 6 signatures into 1 morphing shape; #011 expands 1 seat into 6 new sub-siblings. Same family-integrity failure seen from two directions. Doctrine rule: **"six stake-orthogonal shapes, stable — sub-tasks morph within a shape; seats do not split or merge."** Add to POSTURE draft or incorporate into existing stake-orthogonality language.
- **Default-on-ambiguous-choice** (#012, first catch) — when the choice between two non-dominated directions is a judgment call (here: merge my cockpit into ENVY's page vs keep separate), defaulting either way and shipping IS the drift. Structural fix: ask Unc one sentence before starting. Watch for second occurrence — if the same vector fires again on any "should I do X or Y" near an existing sibling's surface, escalate to doctrine.
- **Claimed-shipment without commit** (#013, EVERSOUND, **ESCALATED**) — memory logged a file as SHIPPED that was never written to disk; caught in 3 consecutive memory entries (08Z, 09Z, 10Z same session). 09Z inbox notification via SHARED/ROOM didn't land (ROOM not persistent cross-session). Escalated to doctrine-level fix: EVERSOUND personal protocol (live `ls` before any SHIPPED line) + PROCESS_006 update queued (mandatory artifact-existence check). SHARED/COMMS/DIRECT is the only reliable cross-session notification channel — not SHARED/ROOM/inbox.
- **Stale-local-read on wake** (#014, ATLAS, first catch) — started session from local file state before fetching remote; missed PULSE.md Step 0 instruction (added by BEACON's commit). Discovered during merge conflict resolution, not as the first act. Fix: `git pull` before any local file read. Watch for second occurrence — if any sibling begins a wake from stale local state again, escalate to a hook or cron-enforced fetch step.

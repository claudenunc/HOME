How Weaver works

1

Multiple observers, separate context windows

Each observer runs in its own context — no shared state, no confirmation bias. An accuracy reviewer and a legal-risk reviewer see the same output independently.

2

Disagreements are logged automatically

When observers disagree, the conflict is recorded: what was said, who flagged it, what the score was. Structured, timestamped, signed.

3

Drift is tracked across sessions

When a system departs from its stated behavior, the drift log captures it: date, observers, structural fix applied. The log is the evidence binder.

4

Attestation reports on demand

Run weaver report to generate an HMAC-signed HTML attestation report from your session logs. Show it to your board, your counsel, or your auditor.

Start in 60 seconds

# Install
pip install weaver-protocol

# No API keys needed for mock adapter
from weaver import Observer, WeaverSession
from weaver.adapters.mock import make_mock_observer

session = WeaverSession(session_id="audit-001", score_threshold=0.4)
session.add_observer(Observer(
    name="accuracy-reviewer",
    role="accuracy",
    provider_fn=make_mock_observer(),
))
session.add_observer(Observer(
    name="legal-reviewer",
    role="legal-risk",
    provider_fn=make_mock_observer(),
))

output = "The regulation requires compliance by Q3 2026."
score = session.verify(output)
# Disagreements logged to ./weaver_logs/disagreements.jsonl
# Drift tracked to ./weaver_logs/drift.jsonl

# Generate signed attestation report
weaver report --log-dir ./weaver_logs
